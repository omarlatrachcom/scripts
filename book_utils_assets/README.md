# Book Utils tokenizer asset

`o200k_base.tiktoken` is the tokenizer vocabulary used by Book Utils when it
creates ChatGPT-safe TXT chunks. It is bundled here so JPG-to-TXT and PDF-to-TXT
work without an internet connection and do not depend on macOS's temporary
`tiktoken` cache.

Source:
`https://openaipublic.blob.core.windows.net/encodings/o200k_base.tiktoken`
